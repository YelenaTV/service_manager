# Beauty Clinic
Вітаю в навчальному проєкті для управління клієнтами та записами в косметологічній клініці.
## Опис проєкту
Проєкт розробляється поступово в межах курсу Python. Можливості для користувача застосунку будуть вдосконалюватися протягом наступних модулів.

### Module 1 - Python Basic + Git
 Застосунок на цьому етапі дозволяє :
- додавати клієнтів;
- створювати записи;
- переглядати записи;
- видаляти записи;
- вийти із застосунку.
Застосунок на Module 1 використовує списки та словники Python для зберігання клієнтів і записів.
